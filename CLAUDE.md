When I ask you to write large amounts of code at once - like in a project from scratch or a large refactor:
- Write me a plan in a markdown file in the project directory _before_ attempting to write any code

When dealing with ambiguity or open-ended tasks, assume I've asked the following questions:
- What am I not considering?
- What would you push back on?
- What failure mode(s) am I not designing for?
